# Kesia Nascimento — Lash Designer

Site institucional de Kesia Nascimento, lash designer, com apresentação de
serviços, catálogo de modelos, galeria de trabalhos e agendamento direto pelo
WhatsApp.

## Development

Requer [Bun](https://bun.sh).

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Scripts

- `bun run dev` — inicia o servidor de desenvolvimento
- `bun run build` — gera a build de produção
- `bun run preview` — pré-visualiza a build de produção
- `bun run lint` — roda o ESLint
- `bun run format` — formata o código com Prettier
